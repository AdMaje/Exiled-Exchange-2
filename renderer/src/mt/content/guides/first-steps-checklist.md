# First steps checklist

A short list to get the fork configured. Tick items here; progress is stored in
the fork's config file and survives restarts.

- [ ] Open the hub from the tray and move it somewhere comfortable.
- [ ] Set a hub hotkey in Settings and check it opens and closes the window.
- [ ] Switch the hub language and confirm every tab follows it.
- [ ] Open the Economy tab once while online, then close and reopen it to check
      the cached table appears immediately.
- [ ] Pick a reference currency and add two currencies to favorites.
- [ ] Change the chart range on a currency that has history.
- [ ] Add a user guide, reload the hub and confirm it is still listed.
- [ ] Open the user guide folder with the folder button and inspect the file.

## Notes

- Use **Refresh** for new prices. The hub does not poll.
- If the network is down, the Economy tab shows the last cached table with an
  offline badge.
- Removing a guide file is safe; it just disappears from the list.
